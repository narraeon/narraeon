# v0.7.4 world-revision epoch fixtures

`epochs/*.json` are world-revision epoch files written by the v0.7.4 release
(tag `v0.7.4`, commit `fec0eadcf630ddbd855491eea0272e4f4063fe58`, package 0.7.4),
the last release before #106 removed the `state_committed` and
`control_published` apply phases. They are not hand-edited. Their current-schema
counterparts are not produced here.

| `revision-7c67cfd6-0d4e-484d-8dc2-158bc6ffb685.json` | `world-control` | `applying` | `control_published` | upgrade to `committed` |
| `revision-b8237417-d572-40f4-83b8-a50423ff27ae.json` | `world-prepared` | `applying` | `prepared` | unchanged |
| `revision-c58e9520-40e7-48b5-a219-e6a7cb801d35.json` | `world-state` | `applying` | `state_committed` | rejected without rewriting |

Generated by `generator.ts.txt`, run against a clean checkout of the v0.7.4 tree
with its dependencies installed (`npm ci`):

```sh
node generator.mts /path/to/v0.7.4-tree /path/to/this-directory
```

The generator saves each epoch through the v0.7.4 `FileNativeWorldRevisionStore`
(which validates against the v0.7.4 schema and writes with its own
`publishJson`), reads it back with the same store, and copies the files out.
Only the lifecycle, phase, and world are chosen by the generator. Epoch IDs and
timestamps are generated; do not regenerate to match current output.
