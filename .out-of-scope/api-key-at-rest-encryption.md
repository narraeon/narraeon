# API Key 静态加密

Narraeon 不对 `config/model-connections-v1.json` 中的 API Key 做静态加密，也不提供从环境变量或 Docker secret 读取密钥的替代来源。

## 为什么不做

V1 是本地单用户（ADR-0004）。Runtime 需要在无人值守时用密钥调用 Provider，所以任何加密方案的解密密钥都只能放在同一台机器、同一个用户可读的位置，安全性并不高于现在的做法：

- 配置文件以 `0600` 写入，目录 `0700`，每次读取都校验权限，过宽时拒绝使用；
- 前端只拿到 `hasApiKey`，不回传密钥；
- 世界归档、游玩上下文与请求编码都不包含凭据。

系统钥匙串在 Docker 与 Android 内嵌后端（ADR-0047）上都不可用。环境变量和 Docker secret 只适合部署时固定的单个密钥，与在界面里创建、复制、切换多个模型连接的产品形态冲突。

如果将来出现多用户或远程托管，密钥的威胁模型会改变，届时重新评估。
