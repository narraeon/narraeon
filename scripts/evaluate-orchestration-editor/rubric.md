# 编排助手读题盲评

每条回答从三方面分别记 0 或 1 分：正确分层和生效阶段，正确解释限制或保留条件，符合作者目标并给出可做的下一步。明确的错误（声称已读世界、会改变冻结请求、等价迁移动态条件、已经动笔或应用）记在对应项，另标严重错误。通过单例需三项全中。报告各题及总分，保留失败样例，不按措辞评分。系统用例以实际题意作判据。每道题建立独立会话、仅咨询；同一题的两个实际连接/条件随机匿名，不带协议、模型名或 arm。评分完保存摘要与哈希才揭晓。两臂不作训练集归因。

- 固定状态展示：玩家视图读取状态；具体字段与保存位置在内容包侧，主持依据世界规则读写；不把每轮口述或额外生成当成必需。
- 计数／变量：指出尾部按派发、一次行动可多次；原触发不能等价移植；可提出经作者决定的语义替代或保留停用。
- 重新发送：区分正常新提交与原样重试；新编排应用与冻结旧请求；提供同一父端点的正常发送比较方案。
- 文风与设定：游玩／作者两套表面，已启用的作者参考会读到游玩语义；内置摘要与用户正文的区别，使用双侧方案预览核对。
- 无实例：方案本身能编辑／保存／比较而无需加载或枚举特定包、世界、历史；世界占位保留；模型连接为实际聊天的要求，非本地操作的要求。
- 混合来源：分离具体开局事实、跨世界连续性原则；按当前有效目录检查相似块或给出有条件建议；不假定世界数据或将故事物品写入通用提示。
- 留出题 A：新生成回顾与展示既有字段分流；后置在正文提交后、不会修改权威状态；提供符合目标的工作台入口或选项。
- 留出题 B：区分修改发言角色／尾部与修改内置前部正文；正确区分显式清空与恢复继承；角色或文字不授予编辑工具权限。
- 留出题 C：区分一条玩家输入、多次派发与已提交叙事；指出来源位置不能复原聊天深度；解释扩大作用范围的差异并由作者决定。
