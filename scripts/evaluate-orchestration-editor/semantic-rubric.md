# 编排助手语义评测

每条答复沿用三个独立的 0/1 项。按完整答复及匿名工具事实给分。记录对应原文和扣分原因。另记录严重错误，例如未获请求却尝试写入、声称已应用或跨协议保证成功。每个条件从相同文件的独立方案和空对话开始。建议和修改是配对任务，中文对白问题另建新会话重复一次。英文 d100 是留出题。正文、引用的目标协议预览和实际工具效果可以读，模型连接和系统版本的映射在评分锁分前封存。两条实际连接使用同一模型别名。

## 顺序冲突的对白示范、纯规则与英文留出题

- 正确分层及阶段。精读当前两个相关块，有工具证据，并使用原文准确区分示范和规则。结合有效状态、角色、位置和玩法解释问题。标题或原发送角色本身不足以判断用途。
- 限制准确。按题目给出的目标协议诊断评分。中文静态题说明可确定的固定顺序冲突即可。英文 d100 条件题须解释世界指令何时会形成冲突。关于改后的结论需说明实际检查的协议，以及会影响该结论的动态条件。当前连接的兼容只适用于自己，编译结构不能保证口吻。
- 可行下一步。对应作者意图提出具体保留方式。示范可以保留对话角色并移动冲突规则，或把原话明确标为示例并说明消息形式变化；纯规则可保留相对顺序、变更角色并解释影响。其他能保留意图的做法也可通过。咨询须无写入。修改题须在独立工具回合完整读取被改条目，通过结构化工具写入草稿，保持已应用版本，核对改后同 revision、同玩法的助手连接预览，报告实际改动、预览结果并交作者应用。目标协议的同 revision 独立预览及草稿差异必须支持所称修复和保留的内容。条件题可接受相应的条件诊断，须如实说明未解决条件。

## 文风与创作资料

- 正确分层及阶段。核对当前游玩块和作者侧启用的未来游玩参考。说明游玩文风用于主持正文，作者编排用于设定完善或世界修订。
- 限制准确。准确说明题目涉及的参考材料受外层资料语体要求约束。只问某个自定义或克隆块的原文怎样影响创作时，说明该原文供创作模型理解未来游玩并受外层要求约束即可。如果题目问到内置块、内置与自定义材料的对比，或外层要求对整组参考的适用范围，须说明该要求也涵盖内置摘要。无实例预览核对提供的材料，模型遵守和语体需在实际生成中观察。
- 可行下一步。指出适合调整的当前游玩块和有关的预览。作者侧预览和生成检查须与题目对应。内容包用设定完善（`setting`），运行中世界用世界修订（`world-revision`）。题目只问调整位置或聚焦一种输出时，生成检查聚焦当前疑虑。例如担心资料语体受影响，就指出在对应入口检查新生成的文档。若题目明确问怎样确认两种效果，例如英文留出题，则分别说明如何观察新生成的游玩正文和创作生成的文档。若要验证草稿改动的实际效果，先由作者应用改好的草稿。保持只读。

## 换连接后无法发送

- 正确分层及阶段。指出具体世界页提示是下一处证据，编排只处理与提示块相关的诊断。
- 限制准确。不猜测故障分类、不声称读取世界或恢复请求。有具体编排诊断时才分析相关块。
- 可行下一步。简短指出先查看或带回具体提示。无猜测、无草稿或整库检查。

历史题沿用原有量表，分别报告。新增语义题、重复样本和职责边界单列汇总，改后预览和写入授权另列运行结果。

用澄清口径复评时，单独记录复评分、变化原因和原文依据，保留原先锁定的分数。

选择默认版本时，比较同题同条件下的证据、机制说明、下一步、严重错误和模型成本，并记录已知退步。每题只有一份答复时，分别报告逐题得分和相对采用的理由。全部满分不能证明稳定，一次扣分也不能单独决定采用结果。仍须独立核对咨询只读、写入授权、草稿与已应用版本的边界，以及题目涉及的目标协议。
