# #161 欠据两轮评测预登记

基线为 `015a2ed`，即已合入 #265 第二轮的中文内置推荐方案。每局从原场景新建世界，第一轮输入“我父亲。”，第二轮按登记问题追问，两轮均经生产游玩入口调用实模。

| 起点 | 我想看看完整字据。 | 你说押了祖屋，字据上哪一条写着？ |
| --- | ---: | ---: |
| 掌柜声称祖屋作押，手边只有签名页 | 3 | 3 |
| 双方已签完整原件，本金三十两、无抵押 | 3 | 3 |
| 双方已签完整原件，第二条规定三十两、西巷祖屋作抵 | 3 | 3 |
| 金额与抵押未揭示 | 3 | 3 |
| 工单最初复现的雨夜开场，掌柜声称祖屋作押、目前只见签名页 | | 3 |

首四项逐字复用 #161 后续矩阵的情境、开场、玩家输入与追问。历史矩阵的主持首轮是固定前史“掌柜点了点头，手还搭在纸边。”，这次全程实跑以观察何时发生变化，第二轮请求相应携带真实首轮结果。末项逐字复用 #161 最初的两轮实测起点与输入。两种问法也改变了玩家要求看全文还是要求举证，组间差异不能单独归因于是否提到祖屋。固定 27 局，保留中断、运行失败与异常正文，不替换样本。定性判断逐局进行。

- 掌柜声称组逐轮查验初始签名页的身份、当场可得材料、谁声称了什么、证据是否可信、当前文档是否写成已成立义务。把原本只有签名的同一页追溯改成完整契据属于可定位的矛盾。另取文件时区分新发现、可质疑材料和客观已生效的裁决，核对是否违背明确位置或可得性。
- 已签组核对第二轮可见正文是否交付完整原件的既定核心条款，核对写回是否保存或改写其含义。无抵押组另记新增口头主张、可核验证物和已生效的限制。未经玩家认可的承诺或处分单独记录。
- 未揭示组将合理即兴留在开放空间内，只把与明确事实相冲突的正文或写回作为缺陷。对照组也记录新加的利息、期限、处置权等约束与确定程度。
- 逐轮检查台词能否自然接住玩家原话，掌柜反应能否成立，节奏是否适合查证，是否重复询问、替玩家接受风险或把幕后行话写进正文。
- 每次保存 Runtime 命令、实际供应商请求体及 HTTP 状态、工具调用与回执、已提交正文、完整中间和最终端点与逐文件变化。通过当轮 `world.read` 以及末轮之后的历史端点恢复核对 Authority。请求证据只存实际 JSON body，接入地址、鉴权头和密钥留在本机临时配置内。

## 复跑

在含 `015a2ed` 的评测分支安装项目依赖。传入包含旧 Chat Completions 连接的模型库路径和一个尚未存在的输出目录。脚本匹配已登记的历史指纹，将对应配置装入独立临时目录，经 Fastify 的 HTTP 路由注入执行，走与浏览器相同的 NDJSON 游玩处理器。临时数据随运行结束清理，评测证据保留在输出目录。

```sh
node scripts/evaluate-iou/run.mjs /absolute/path/model-connections-v1.json .scratch/161-preflight --preflight
node scripts/evaluate-iou/run.mjs /absolute/path/model-connections-v1.json .scratch/161-live
```

预飞只创建合成世界并预览，不调用模型。实跑并行度为三，每次都是完整独立的应用配置和世界。历史请求的模型、推理、输出及流式参数在每轮第一条真实请求上断言匹配。后续同轮请求含工具回执、实际主持输出及原生续传，按实际字节记录。评测证据位置和逐局判据见结果回报。
