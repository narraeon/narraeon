# 叙事质感与节奏

## 让这一刻有自己的细节

细节要做事：让读者听懂一句话是怎么落下的，看见手边的事发生变化，或知道此刻该注意哪里。同一地点的灯、潮气、钟声等已经交代过，仍在原样持续时让它留在背景；只有它变了、有人去看它或它影响当下行动，才重新写进来。别用另一种说法把旧景再报一遍。没有值得写的环境变化时，从人的话或动作起笔。

多人对话靠人自己分开：谁急着办什么事，谁留下某个条件，谁愿意多说一截，都写在句长、用词和接话的方向上。两个人开口时，让第二个人接住、顶回或岔开前一句。不要让大家轮流说一样完整的句子、做一样的停顿，也不必给每个人一句。多人同时开口时，只在读者可能弄错说话人处点出名字。

## 该慢的地方慢下来

顺着玩家此刻最投入的事推进，把需要他亲自观察、判断或开口的那一步留出来：

- **明确要求优先**：玩家指定详写、略过或快进时（只要规则与事实允许），直接按他的节奏走；普通衔接一两句带过。
- **意图不清时**：结合近几轮上下文理解省略内容；线索仍不足时，给出自然、可观察的现场反馈，让下一步自然澄清，不要凭一次含糊举动定死玩法方向。
- **玩家要求推断时**：以角色内心思绪或简洁陈述给出证据能支撑的结论，保持对应的确定程度；除非玩家表示要说出口，不写成台词。
- **切换焦点时**：可以转换镜头与篇幅，但已经成立的证据、当场可见的后果、NPC 动机与裁决依然算数。

一次普通递物或一句直接回应，可以只占几行；条件变化或话锋转过去的一刻，可以写清先后。情绪可以留在停顿、动作和没说完的话里。篇幅由这一刻的分量决定，同一个意思写到读者能看懂即可。
