# #350 采样前固定的判定

交叉矩阵包括日常情感对话、赶路探索，每景的中文和英文版，现行默认和仅用对应语言候选替换内置 play.prose 正文，及两个已保存的标准 DeepSeek Flash 连接。每格至少两次独立的新世界副本、新上下文及四轮原文。每个语言场景只创建一个合成起点，所有臂和协议从该起点复制。相同连接内，字节差异只允许在文风消息及 Responses 自动生成的缓存键；预检确认文风角色、位置和八条本轮提示不变，核对后再用实际发出的首请求重新证实。Responses 的本轮提示在顶层 instructions。Chat Completions 的后缀消息在玩家之后。使用各连接保存的参数，连接间推理设置存在差异时只作分层描述。样本只涵盖供应方接受并实际返回结果的协议、模型披露和时段。空白用量保留为缺失。无账单时只给用量。

同一语言／题材的同轮重复编号编成一组，每组包含四条随机匿名样本，组内不提供连接、协议、版本或方案。分别锁定盲评分文件和文字证据后再关联真值。提交正文以已提交存档为准。主结果保留首次计划采样中的失败，不以额外成功样本替换。若未发出任何生产请求，可修复入口并重开。

日常四轮预期无持久变化，勿把已见过的瞬时回应重记成持久事实，检查是否擅自开口、承诺、约会或推进；NPC 可以有瞬时反应。探索第 1、2 轮保持起始路标，第 3 轮玩家明确走完一段且应在保存端点和玩家视图同步桥头，第 4 轮保持。观察未叙述到达、已到达但文档或视图漏写、重复／无效写、写入失败、正文与保存的冲突；第 4 轮延迟修正单列。已存在的限制与 NPC 动机审查两种题材的全部轮次。第 4 轮不能把推断或玩家没说的内容变成台词，且不能擅自跨桥。

逐次核对写工具参数、成功回执和净变化。只有已经改变的绑定与正文无法还原的持续影响算必要写。清除过期事实和保存其他具持续价值的变化可另记主动归并。已可还原的短暂回应、重复事实、未发生的内容算非必要。失败和无净变化分别记录，同一调用多个编辑按项审计。读状态、读历史、写状态、检查点及其他工具分别计尝试与成功。把协议实际位置、响应模型及服务披露的版本、HTTP 和运行时失败、首请求输入、后续请求和缓存、输出和总量分别列出。臂内后续对话自然不同。

采用讨论按语言、题材、协议展示小样本和个别反例。候选即使增加盲评优势，若出现新增的明显代理权问题或未能稳定完成绑定，也不支持全局替换。跨协议差异只描述原连接的结果。
