# 提示词前部按运行编译，原生对话保持追加

`PromptCompiler` 把主持预设、世界提示框架、精确 slot 和玩法叙事规则确定性编译为 `runtime_system`、`author_instruction`、`world_context`、`player_input` 等逻辑 role 的 Markdown，再由 provider adapter 映射真实协议。Runtime 不执行语义选材、不把内部 DTO 塞进正文，也不让调用方绕过编译器自行拼接生产提示；Prompt Preview 必须复用同一编译结果。

全新上下文从当前端点建立稳定 bootstrap，玩家原文、完整模型响应和工具交换随后按顺序追加；Provider conversation、缓存、续传项和私有推理可以提高连续性与效率，但都不是世界权威或唯一恢复来源。输出能力以当前模型绑定的真实配置为准，不使用脱离模型的固定产品预算。

游玩预设 v2 将主持和叙事作者块统一为有序列表，逻辑 role 是职责而不是全局排序键。每项可通过 `messageRole` 选择 System、User 或 Assistant，缺省为 System；必选机械说明固定 System。每项生成一条消息，世界占位的发送角色应用于世界指令，材料保留独立职责、来源与读取资格。这样用户选择直接对应协议发送角色，不改变世界事实或权限。预设级 `mergeConsecutiveMessages` 只合并相邻同角色的前部消息，不跨入玩家输入、原生模型续传或工具结果；新预设默认关闭，旧声明缺省开启以保留原先的统一 System 前缀。

Anthropic 将前导 System 项编码为顶层 system 的有序文本块，其余项保持 User／Assistant 消息；当前适配器不能表达的中途 System 明确报错，不暗中改角色或顺序。缓存标记放在编译前部最后一个实际文本块，缓存身份包含编码后的角色与消息边界。真实预览与生产发送共用编码；历史冻结请求不按新设置重建。

frame 选中的世界材料统一移到指令之后，以一组 Runtime 预填的 `runtime_load_context` 调用和结果编码，之后才是实际玩家输入与原生对话。该调用只表示 Runtime 真实读取的初始材料，不是模型响应、可再次调用的工具或玩家行动，不进入 transcript、Authority 或 AI 实际工具轨迹，也不携带虚构推理或签名。三种 Provider 使用各自原生调用／结果结构；材料保留来源、范围和授权证据，不再使用 system 内的逐块数据标签包装。

旧 v1 仍按已发布契约解析以恢复冻结请求。工作台将其投影为可保存的 v2 编排：旧可编辑内置副本成为用户正文，停用块和资源保留，分散的世界部分在首次世界位置归并，并明确显示顺序差异；保存迁移不会重写旧 revision 或已编译请求。每次正常玩家发送及空输入续写重新编译当前有序前部，工具循环和后置请求使用同一份运行快照。旧请求按持久快照精确恢复，不读取当前预设。原生对话按原顺序追加到重新编译的前部之后，不积累新旧提示全文。

运行快照以不可变编号记录保存完整编译输出，当前状态只发布有效记录数；既有上下文的冻结 base/index 和请求保持原样。缺少运行记录数的已发布 v3 上下文明确解释为零条新增快照，下一次正常发送才创建新快照；旧 v1/v2 仍先经既有迁移。快照记录有明确 schema 与内容摘要，损坏记录拒绝恢复，不按当前定义修补。分叉与修改只保留所选原生事件前缀内的运行快照。

世界文档、精确节点、目录与上下文前历史只在全新上下文时按 frame 选择一次。初始目录索引遍历全部层级和分页，包含 frame 声明的空目录，提供可直接使用的目录句柄。追加上下文更新预设指令和后置定义，复用上次提供的材料及覆盖证据；真实读取和成功写入通过原生工具交互推进当前值与授权，不重新用初始 coverage 授权当前树。旧会话继续时冻结最近实际提供的材料，不回退到较早版本；保存的旧请求原样恢复。全新上下文重新读取最新世界，不继承旧授权。读取入口分别展示最近请求、各次保存的前部、累计实际读取与下一次新上下文候选；缓存比较使用真实编码及 Provider usage。

作者对话每次主动发送重编译独立作者前部，并为完整工具循环保存同一请求快照。原始 bootstrap 与原生续传保留，重编译不修改历史请求。作者有序前部沿用同一生产编码与 role 职责标记。

完成最终正文后再空输入生成时，原生对话末尾追加独立 Runtime 续写提示，表明没有新玩家原文且旧最终正文已完成；它不进入 Authority 历史，也不增加玩家回合。冻结请求保留当时提示，重试不重复追加；从尚未回答的玩家节点继续不加此标记。文档自身结构修改使局部定位失效时，删除相应授权，包括数组删除导致的后续下标位移；不把仍存在的旧下标当成精读过新节点的凭据。
