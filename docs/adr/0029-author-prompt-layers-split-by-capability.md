# 作者提示词按各层实际能力划分

作者提示词按每一层实际拥有的作用域与写入能力划分：跨世界恒真的文风、玩家代理权和通用状态维护原则属于主持预设；本世界特有的题材边界、文档类型、保存位置与材料声明属于世界提示框架；玩法预设只提供玩法工具、扩展配置和稳定叙事规则；描述 Runtime 输出、工具和机械边界的内容由 Runtime 生成。`world_context` 只承载材料，作者层不能用它伪造世界事实。

设定完善只能改写内容包中的世界提示框架，不能触及工作区级主持预设，因此通用判据不会因一次世界设定修改而静默消失。Runtime 不校验某段自然语言是否写在正确文件中；Prompt Preview 负责把最终组合完整展示给作者。
