# 世界状态是文件原生当前树

内容包 `world` 中的受限 YAML／Markdown 在创建世界时直接复制为该世界唯一的 `state` 当前树，`control` 进入独立控制面，发布后两者都与来源内容包脱离。世界专属字段、类别、关系、范围和状态转换只由开放文档与作者语义表达；Runtime 只校验文件安全、最小文档身份、显式引用、精确 locator、写前读取、候选修改、端点和原子提交，并以变化后完整文件、精确叙事和下一端点材料清单形成不可变恢复来源。

这个边界接受 Runtime 无法机械判断 `好感度: 150` 或 `修为: 菠萝` 是否合理，换取人类可读、可扩展且能直接作为模型材料的世界。玩家视图只按精确选择器投影当前文档，不承担秘密分类、权限证明或通用 schema 投影。
