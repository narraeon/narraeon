# 玩法产物经频道投影到可信前端扩展

状态栏、行动选项、地图和调试结果以带来源、频道与保留策略的非权威玩法产物保存，再由 append、replace、upsert、transient 或 hidden 频道策略机械投影；它们不塞进世界状态或已提交叙事。Runtime 负责持久化、端点绑定和能力边界，可信前端扩展宿主负责正则、Markdown、HTML、JavaScript 与有限界面 bridge；第一方界面产物必须使用同一公开扩展契约，脚本不能直接取得模型工具或权威提交能力。

系统后置示例的产物随生成记录保存当时的声明、资源与挂载位置；冷恢复和前端投影使用这份冻结呈现，不查询当前应用示例。旧用户产物仍由原精确预设 revision 解析，不改写原记录。

渲染宿主在 document 与 app 模式统一应用声明的 CSS 资源，工作台预览复用同一路径；CSS 中的 `<` 编码为 CSS 转义，不能通过结束 style 标签引入 HTML。其他资源继续保留原资源映射，JavaScript 仍仅在 app 模式及已有脚本授权下执行，CSS 不改变脚本门控和 iframe 隔离。
世界数据驱动的纯界面面板与模型产物共享此宿主和标准挂载。纯界面来源是已提交玩家视图，生命周期跟随当前预设与世界端点；它不持久为后置产物，也不触发模型。工作台预览采用同一投影和宿主，以显式世界的安全视图及当前草稿资源为输入，保留既有脚本权限与隔离边界。

内容包产物使用同一后置运行器与冻结呈现，但请求和频道带独立 `package:` 作用域，资源从复制后的世界 control 解析。脚本许可独立保存在来源的 Runtime 本地外壳，按冻结资源内容指纹授权；预设的本地信任不传递给内容包，便携包不能携带许可。创建世界与分叉在 staging 复制当时许可，随后独立；撤销许可即时影响后续投影而不改写冻结产物。这避免把历史资源恢复与当前代码执行许可混为一份不可撤销的历史授权。
