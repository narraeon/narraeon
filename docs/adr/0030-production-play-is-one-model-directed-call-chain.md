# 生产游玩统一为模型主导的调用链

生产游玩只有“全新上下文”和“追加上下文”两个提交动作，不区分独立回合与连续会话，也不由 Runtime 编排裁决、叙事或集中结算阶段。全新上下文从当前端点重新编译稳定 bootstrap 并追加首条玩家原文；追加上下文继续现有 transcript，空输入时直接续写，没有上下文时自动全新开始。

玩家原文、工具中间步产生的世界变化和终态无工具响应中的非空叙事分别推进 Authority，后续失败不会回滚已经成立的前序提交。只要完整响应含有工具调用，其中的 text 就只保留在可恢复调用轨迹和 Provider 原生续传载荷中；模型收到工具结果后再用无工具响应完成叙事。工具调用、Provider 返回推理、待定流式片段、失败与 usage 保留在页面调用轨迹中，但不因此成为世界权威。Runtime 在模型派发前保存完整请求，但只有 Provider 明确拒绝或持久状态能证明尚未派发时才允许原样重试；流中断、传输失败或进程可能已开始派发却没有完整结果时属于 outcome unknown，旧请求不能重放，中断片段也不进入模型上下文。完整响应的后续追加遵循 [ADR-0035](0035-provider-continuation-is-opaque-and-bound.md) 的协议原生续传规则。

运行中的调用链把阶段、耗时、最近数据时间和已接收增量作为 Runtime 临时进度投影；页面刷新可以重新读取，进程重启后则只能按持久推进事实恢复，不能假造仍在运行的模型。只有 Provider 明示返回 reasoning 时界面才称为思考。玩家取消按 world、chain、exchange 精确寻址并向实际 Provider 请求传播 AbortSignal；已提交玩家原文与此前 Authority 不回滚，未结算片段不进入 transcript 或故事。派发后的取消保持不可重放，派发前取消仍可原样继续。浏览器流断开不代表玩家取消，呈现失败不能改变 Runtime 中调用链的执行与 Authority 结果。

全新上下文只替换模型 transcript，页面时间线继续保存此前上下文；历史玩家消息的“修改”与独立世界的“创建分叉”采用 ADR-0032 定义的不同 Authority 操作。这个模型允许 AI 自行交错读取与写入，但把叙事收口在工具完成后的终态响应；Runtime 不编排独立裁决／叙事阶段，只机械区分工具中间步和终态叙事。连续性质量仍依赖作者语义、模型能力和真实验收。

游玩中的内容离场与内容包整理使用不同原语。`world_patch` 支持按 map key 或数组下标精确 `remove` 一个 YAML 节点；游玩不物理删除整份状态文档，而用 `world_retire` 设置可恢复的退役状态。退役文档继续留在 Authority，可列出、搜索、读取和引用，但不再进入后续全新上下文的 frame catalog。恢复同一文档只需清除退役状态，不创建新身份。ref 仍不可修改，文档也不能用 move 覆盖另一条路径。
