# Chat Completions 是 v1 的模型 API 兼容基线

V1 在本地保存可手动切换的模型连接，以 OpenAI-compatible Chat Completions 作为默认兼容适配器，并同时提供 OpenAI Responses、原生 Anthropic Messages 和 Google Interactions 适配器；产品不固定供应商、模型或自动故障转移。连接必须通过显式能力测试，配置中的推理强度、流式、工具调用和续传信息由对应 adapter 原样映射；远程 conversation、缓存和私有推理只能加速 ModelHost，不能成为世界连续性或恢复来源。

Google Interactions 可从端点拉取模型列表或手工输入模型 ID，可使用标准或 CLIProxyAPI 方言。默认连接省略推理参数；可显式设置 thinking_level（minimal、low、medium、high）或兼容预算，摘要 thinking_summaries（auto、none）独立选择。标准兼容预算采用旧格式 thinking.thinking_budget，CLIProxyAPI 使用 thinking_budget；自动为 -1，关闭为 0，手动提交非负整数。各模型与端点分别判断是否接受。CLIProxyAPI 按操作发送 X-Session-Id，Google 缓存始终由端点管理。参见 [Interactions 请求字段](https://aistudio.google.com/api-reference/interactions-api/create-interaction)和[旧版预算说明](https://ai.google.dev/gemini-api/docs/whats-new-gemini-3.5#thinking-budget)。没有任何具体模型或服务版本已经通过真实四入口验收。适配器编码和合成传输测试不证明服务支持该模型、工具 schema、签名或 token 续接。System、绑定和恢复边界见 [ADR-0035](0035-provider-continuation-is-opaque-and-bound.md) 与 [ADR-0038](0038-world-revision-uses-one-locked-worktree.md)。
