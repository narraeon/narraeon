# 已提交叙事保存可选情境背景

为解释旧原文里的“明天”“这里”，Runtime 仅从 `bindings.currentSituation` 精确绑定的受限 YAML 文档读取顶层 `背景`，把完整节点的公开 YAML 值与消息一起保存；字段内部仍由作者与模型负责，不引入历法、地点或视角 schema。缺失、null、空白字符串、空映射与空数组不采集，0 与 false 保留，不清理嵌套内容、不展开引用、不返回兄弟字段。

开场白取世界起点，玩家原文取接受输入时的已提交状态。主持段落在工具修改前冻结文档身份与起点值，工具往返、冻结请求重试和崩溃恢复保留它，最终正文的准备结算保存同一绑定的终点值；正文成功提交后的空输入续写建立新起点。工具中间正文不形成历史消息。分叉保留可达消息记录，尚待生成的正文以所选端点状态作为新段起点（包括工具结算端点）；玩家修改稿按逻辑父端点重新采集。世界外修订、改名和绑定调整均不改写旧背景。

背景作为既有消息的可选关联字段进入 Authority 内容摘要、operation 幂等比较与恢复；既有 v3 记录缺省为未记录，不迁移或回填不可变事实，既有冻结推进缺少起点时继续不记录。公开节点序列化为完整 YAML，避免历史读取依赖现在的引用身份或文档树。`runtime/history-backgrounds` 是按消息身份保存、随物化端点发布且可由 Authority 重建的投影，原文 Markdown 保持原样；普通历史读取直接读取此投影，无需逐条恢复世界树。

HistoryQuery 的快照包含背景，HistoryRendering 在原文边界之外统一标注：两端值相同只显示一次，不同则分别显示推进前／后，单端缺失明确未记录。工具、recent、附加材料、检查点补充和真实预览均携带独立可解释的记录；搜索、偏移与长度仍只计算原文。历史背景说明采集位置的状态，不代表当前状态、事实认证、整段逐句日期或角色知识。这扩展 [ADR-0024](0024-world-state-is-a-file-native-current-tree.md) 的开放文档约定与 [ADR-0040](0040-history-navigation-shares-an-ordered-snapshot.md) 的共用历史快照，避免引入完整历史情境查询和第二份内容配置。
